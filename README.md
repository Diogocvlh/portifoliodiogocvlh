# Meu Portfólio

Este projeto foi desenvolvido com foco em um portfólio moderno, responsivo e profissional.

## Sobre o projeto

Este site foi criado para apresentar meu trabalho como desenvolvedor, destacando projetos, habilidades e formas de contato de maneira visual e estratégica.

## Tecnologias utilizadas

Este projeto foi construído com as seguintes tecnologias:

- **Vite**
- **TypeScript**
- **React**
- **shadcn-ui**
- **Tailwind CSS**

## Como editar o projeto

Você pode editar este projeto de diferentes formas:

### 1. Editando localmente no seu computador

Se preferir usar sua própria IDE, siga os passos abaixo.

#### Pré-requisitos
- **Node.js**
- **npm**

Caso ainda não tenha o Node instalado, você pode usar o **nvm**:  
https://github.com/nvm-sh/nvm#installing-and-updating

#### Passo a passo

```sh
# 1. Clone o repositório
git clone <YOUR_GIT_URL>

# 2. Acesse a pasta do projeto
cd <YOUR_PROJECT_NAME>

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev

To connect a domain, navigate to Project > Settings > Domains and click Connect Domain.

Read more here: [Setting up a custom domain](https://docs.lovable.dev/features/custom-domain#custom-domain)
